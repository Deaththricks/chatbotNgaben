# LLM layer (coreference resolution + answer synthesis) — Qwen 2.5 via a local
# Ollama server. (An earlier Groq-based rephrase-only layer, Chatbot/bot/llm/, was
# fully superseded by this and deleted 2026-09-18 — see PROJECT_CONTEXT.md and
# HOW_IT_WORKS.md §8.2 for the history, if you're wondering why this comment
# mentions Groq at all.)
# These two packages only give Python a way to TALK to Ollama over HTTP — they do
# NOT install Ollama itself or the model. Ollama is a separate, non-pip program
# that must be installed and running on its own (https://ollama.com), and the
# model it will serve must be pulled once before the bot can answer anything:
#   ollama pull qwen2.5
#   ollama serve        # or just leave the Ollama desktop app running
# actions.py calls this local server on every single turn with no offline mode —
# if Ollama isn't reachable, the bot degrades to a plain templated answer (or, for
# the free-form fallback path, a fixed "gangguan teknis" message) instead of
# crashing, but it never gets a real LLM-written response until Ollama is back.
langchain-core>=1.6
langchain-ollama>=1.1
