#                         # meaning search.

# LLM layer (coreference resolution + answer synthesis) — Qwen 2.5 via a local
# Ollama server. (An earlier Groq-based rephrase-only layer, Chatbot/bot/llm/, was
# fully superseded by this and deleted 2026-09-18 — see how_it_works.md §8.2 for
# the history, if you're wondering why this comment
# mentions Groq at all.)
# These two packages only give Python a way to TALK to Ollama over HTTP — they do
# NOT install Ollama itself or the model. Ollama is a separate, non-pip program
# that must be installed and running on its own (https://ollama.com), and the
# models it will serve must be pulled once (see the top of this file):
#   ollama serve        # or just leave the Ollama desktop app running
# actions.py calls this local server on every answered turn (the answer itself; the
# term-extraction call only when the message needs it) with no offline mode -- if
# Ollama isn't reachable or times out (LLM_TIMEOUT), the bot degrades to a plain
# definition-based answer (or, for the free-form fallback path, a fixed "gangguan
# teknis" message) instead of crashing, until Ollama is back.
# client_kwargs={"timeout": ...} on ChatOllama needs langchain-ollama >= 1.1.
langchain-core>=1.6
langchain-ollama>=1.1
# kb_semantic.py calls Ollama's embed endpoint through this client directly (Client.embed
# with options, 0.6.2 in the venv as of 2026-10-12).
ollama>=0.6
